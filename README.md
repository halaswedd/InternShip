## Installation

1. Clone the repository.
2. Import the SQL file located in the `database/` folder into phpMyAdmin.
3. Ensure the database name matches the one specified in `backend/config.php`.
4. Start Apache and MySQL using XAMPP.
5. Open the frontend directory and install the required dependencies:
   npm install
6. Start the React development server:
   npm run dev

## Notes

* This project is configured for local development using XAMPP.
* Database connection settings can be modified in `backend/config.php` if necessary.
* The SQL database file is included in the `database/` folder for easy setup.
